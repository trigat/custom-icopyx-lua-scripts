# Custom iCopy-X Lua Scripts
Created by Trigat.

## About
These Lua scripts extend the functionality of the iCopy-X beyond the built-in options.

For example, the ICLASS_LEGACY_CLONE.lua script allows cloning of HID iCLASS Legacy tags without requiring the proprietary iCopy-X iCLASS card.

Note: Testing has only been performed on iCopy-XS OS v1.0.90.

These projects and references have been especially helpful:

- [RRG / Iceman Repository](https://github.com/RfidResearchGroup/proxmark3)
- [iCopy-X Community Teardown](https://github.com/iCopy-X-Community/icopyx-teardown)

## Installation
1. Plug the iCopy-X into a computer and enable PC-Mode.
2. On the computer, open the ICOPY-X storage device.
3. Copy the Lua scripts into the existing /luascripts directory.
4. Exit PC-Mode.

The scripts will now appear in the iCopy-X LUA Script menu.

## Usage

All script filenames are capitalized so they can be easily located in the LUA Script menu.
